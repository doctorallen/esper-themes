Esper Theme Specimens

Every Esper theme as it ships, drawn as VS Code draws it, in the Modern UI or the classic layout. Pick a theme to open it large: click any part of the window to see the theme keys that paint it and swap them for another color from the theme's own palette, or pick a swatch to change every use of a color at once. Edits stay on this page until you export them. Regenerate with npm run build:specimens-page; the study behind these choices is theme-census.html.

Each window shows the active and inactive activity items, the selected file with the tree focused (folder tree) and unfocused (Open Editors), git- and problem-decorated rows, an active, an inactive and a modified tab, a find in progress, bracket pairs, the terminal's normal and bright colors, and the status bar's remote, error and warning items.
