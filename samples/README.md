# Theme Samples

These original source fixtures exercise the Esper themes across common language
grammars. They are for visual development and manual theme checks only, and are
excluded from the packaged VSIX.

| Language | File | Syntax exercised |
| --- | --- | --- |
| Angular | `angular/relay-dashboard.component.ts` / `.html`, `relay-telemetry.service.ts`, `relay-telemetry.models.ts` | Standalone components, signals, RxJS streams, service injection, inputs, outputs, control flow, bindings, and pipes |
| TypeScript | `typescript/telemetry.ts` | Types, generics, enums, async functions, decorators, and errors |
| JavaScript | `javascript/event-bus.mjs` | Classes, private fields, optional chaining, maps, and promises |
| CSS | `css/status-panel.css` | Custom properties, selectors, pseudo classes, media queries, and animations |
| HTML | `html/status-panel.html` | Semantic elements, attributes, forms, templates, and inline scripts |
| Python | `python/signal_processor.py` | Dataclasses, type hints, decorators, generators, and exceptions |
| Rust | `rust/main.rs` | Structs, enums, traits, pattern matching, results, and tests |
| Go | `go/main.go` | Structs, interfaces, goroutines, channels, maps, and errors |
| PHP | `php/RelayReport.php` | Namespaces, enums, typed properties, attributes, exceptions, and closures |
